# Contributing to Project NETRA

Thank you for your interest in contributing to Project NETRA! We welcome contributions from the community to help improve this intelligent traffic management system.

## 🤝 How to Contribute

### Reporting Bugs

If you find a bug, please create an issue with the following information:
- A clear and descriptive title
- Steps to reproduce the bug
- Expected behavior vs actual behavior
- Screenshots or video recordings (if applicable)
- Your environment details (OS, Python version, dependency versions)

### Suggesting Enhancements

We welcome suggestions for new features or improvements! Please create an issue with:
- A clear description of the enhancement
- The motivation and use case
- Any potential implementation ideas

### Pull Requests

1. **Fork the Repository**
   ```bash
   git clone https://github.com/your-username/Project-NETRA.git
   cd Project-NETRA
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   - Write clean, readable code
   - Follow Python PEP 8 style guidelines
   - Add comments for complex logic
   - Test your changes thoroughly

4. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Add: Brief description of your changes"
   ```

5. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Open a Pull Request**
   - Provide a clear description of your changes
   - Reference any related issues
   - Include screenshots or demo videos if applicable

## 📋 Development Guidelines

### Code Style
- Follow PEP 8 conventions for Python code
- Use meaningful variable and function names
- Keep functions focused and modular
- Add docstrings to functions and classes

### Testing
- Test your changes with different video inputs
- Verify that the ambulance detection works correctly
- Ensure CSV logging functions properly
- Check for memory leaks in video processing

### Documentation
- Update README.md if you add new features
- Add inline comments for complex algorithms
- Update requirements if you add new dependencies

## 🎯 Areas for Contribution

We especially welcome contributions in these areas:

### High Priority
- **Night Vision Module**: Implement low-light/thermal imaging support
- **IoT Integration**: Connect to physical traffic light hardware
- **Performance Optimization**: Improve frame processing speed
- **Model Training**: Enhance ambulance detection accuracy

### Medium Priority
- **Web Dashboard**: Create a real-time monitoring interface
- **Multi-Camera Support**: Handle multiple camera feeds simultaneously
- **Alert System**: Add notifications for traffic anomalies
- **Database Integration**: Replace CSV with a proper database

### Documentation
- Tutorial videos or guides
- Code examples and use cases
- Translation to other languages
- API documentation

## 🐛 Issue Labels

- `bug`: Something isn't working
- `enhancement`: New feature or request
- `documentation`: Documentation improvements
- `good first issue`: Good for newcomers
- `help wanted`: Extra attention needed
- `priority-high`: Critical issues

## 💬 Communication

- Ask questions if you're unsure
- Provide context in your communications
- Follow the code of conduct

## 📝 Code of Conduct

- Be welcoming and inclusive
- Respect differing viewpoints
- Accept constructive criticism gracefully
- Focus on what's best for the community
